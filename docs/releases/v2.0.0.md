# maintainerd-auth — v2.0.0 Release Scope

v2.0.0 builds on the complete v1.0.0 foundation. The theme is **enterprise depth, developer reach, and operational maturity** — features that make the platform competitive for large organizations, easier to integrate, and more resilient at scale.

Nothing here is a bug fix or correction of v1. Everything is additive.

## v2.0.0 Priority Order

Not everything in v2 is equal. Recommended sequencing:

### Phase 1 — Enterprise Adoption Enablers
These unlock the largest set of paying / enterprise self-hosters:
1. LDAP / Active Directory
2. ABAC + policy engine
3. Hierarchical orgs + delegated admin
4. Adaptive MFA / risk scoring
5. SIEM streaming export
6. SOC 2 + GDPR compliance docs

### Phase 2 — Developer Reach
These accelerate community growth and integration:
7. TypeScript + Python SDKs
8. `maintainerd` CLI
9. Terraform + Helm production-grade
10. OpenID Conformance certification

### Phase 3 — Protocol Depth
For teams that need financial-grade or bleeding-edge security:
11. FAPI 2.0 + JAR + JARM
12. Rich Authorization Requests (RFC 9396)
13. Multi-region HA
14. SCIM outbound push

### Phase 4 — Ecosystem & Operations
15. Grafana dashboards + analytics
16. Webhooks dashboard + CloudEvents
17. Supply chain hardening (SLSA 3, SBOM)
18. Public docs site + community
