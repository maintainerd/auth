# maintainerd-auth — v1.0.0 Release Scope

This document defines what ships in **v1.0.0** — not an MVP, but a complete, production-grade identity server that can stand alongside Keycloak, Zitadel, and Auth0.

The goal is a shippable product that teams can self-host, extend, and build on with confidence. Features that are real but not required to make v1.0.0 complete are tracked in [v2.0.0.md](v2.0.0.md).

---

## Repository Map

| Repo | Purpose |
|------|---------|
| `maintainerd-auth` | Identity server — REST API (this repo) |
| `maintainerd-auth-console` | Admin console UI (separate repo) |
| `maintainerd-auth-identity` | End-user identity portal — account management, OAuth2 consent, login UI (separate repo) |

All backend APIs required to drive both frontend repos are part of this v1.0.0 scope.
